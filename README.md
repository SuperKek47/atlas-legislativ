# Atlasul legislativ

Harta legislației Republicii Moldova, ca joc: citești articolele, le rezumi, dai grile și spețe, înfrunți mini-boșii și cucerești raioanele.

Aplicația se deschide în browser și se poate instala pe telefon (Safari → Partajare → Adaugă la ecranul principal). După prima deschidere merge și fără internet. Progresul se salvează doar pe dispozitivul tău.
